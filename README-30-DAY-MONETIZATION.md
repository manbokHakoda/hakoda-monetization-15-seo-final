# HAKODA MANBOK — 30-Day Monetization Package

## What was changed
- Stronger SEO metadata and canonical URL
- Open Graph / Twitter metadata
- WebSite structured data
- Ad-ready placeholders (no fake AdSense code)
- Digital services / direct-revenue section
- Contact section
- About / Privacy / Terms / Contact pages
- robots.txt
- sitemap.xml
- ads.txt.example

## Before deploying
1. Replace `YOUR-EMAIL@example.com` in `index.html` with the real contact email.
2. Deploy the whole folder to Vercel.
3. Open the live site and test every menu item.
4. Add the site to Google Search Console and submit `/sitemap.xml`.
5. Apply for AdSense when the content is ready.
6. After Google provides the AdSense code, paste the exact code Google gives you into `<head>`.
7. After approval, replace `ads.txt.example` with the exact `ads.txt` line supplied by Google.

## Important
Do not add fake publisher IDs, buy traffic, use bots, exchange clicks, or ask visitors to click ads.
